# Start here. Only this file. Nothing else yet.

You need one thing: a terminal open in the project folder
(the folder that has `oanim` in it).

## Do this now (3 steps, 5 minutes)

**Step 1.** Paste this in the terminal, press Enter:

```sh
./oanim render course/lesson1.py --mode preview
```

Wait a few seconds. Last line says `WROTE course/lesson1.preview.mp4`.
That means it worked.

**Step 2.** Open the file `course/lesson1.preview.mp4`. Watch it.

**Step 3.** Check: dust wanders, then becomes the word GROWTH.

![first video](learn_frames/l1_first.png)

It ends like this. Grainy dust letters. You just made a video with the tool.
